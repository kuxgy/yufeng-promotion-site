01写在前面：为什么每个销售都要做线上推广

核心逻辑：客户买房前一定会先在手机上搜、先在短视频里看。谁先出现在客户的手机屏幕里，谁就先拿到客户。

线上推广不是"额外工作"，而是把售楼部搬到客户手机里。一条好视频可能带来一组到访，一个稳定更新的账号就是你的长期获客资产——客户换项目、换城市，只要还关注你，就还有机会。

三个认知转变

❌ 旧思维

  • 等客户上门、等渠道带客
  • 发朋友圈就是做线上
  • 拍视频要专业团队、要花钱
  • 内容是营销部的事

✅ 新思维

  • 主动出击，让客户找到你
  • 多平台布局，公域+私域联动
  • 一部手机+真实感就够了
  • 每个人都是项目的自媒体
本手册的目标 让一个完全没做过线上的置业顾问，照着步骤在1周内开通4个平台账号，2周内稳定产出内容，1个月内拿到第一波线上咨询。不需要专业设备，不需要会剪辑，手机就能完成。

02账号开通篇：四平台从0到1

📌 本章说明 本章给出两条路径：路径A是做认证（企业号/个人职业认证），路径B是不做认证（纯个人号）。本项目默认走路径B（不做企业认证，员工用个人手机号自主运营），但路径A一并列出，供有条件的同事或未来政策变化时参考。有房地产经纪人资格证的个人，也可以单独做"个人职业认证"（黄V），属于路径A的轻量化版本。

2.3 路径B：不做认证（纯个人号）—— 本项目默认路径

个人账号的合规边界

不做认证不代表不能做房产内容，关键是把账号定位为"买房顾问/本地生活分享者"，而不是"售楼员"。

✅ 个人号可以做

  • 分享买房知识、选房技巧、贷款常识
  • 拍看房vlog、样板间实拍、小区实景展示
  • 介绍本地配套、学校、商场、公园
  • 回答"靖西买房要注意什么"这类通用问题
  • 记录置业顾问的工作日常
  • 通过私信与意向客户一对一沟通

❌ 个人号不能做

  • 公开报价、喊"特价房""内部价"
  • 视频/简介/评论区留手机号、微信号
  • 挂营销组件、小风车、店铺链接
  • 说"找我买房有优惠""独家渠道价"
  • 直播直接卖房、逼单、收定金
  • 用"售楼处直销""开发商直签"等营销话术
💡 核心策略：公域做内容建信任，私域做转化 个人号在公域平台只做内容分享和人设建立，不做直接销售动作。客户感兴趣后通过私信沟通，再引导到微信/电话/售楼部完成转化。把"卖"的动作放到私域，公域只负责"让人找到你、信任你"。

四平台个人账号开通步骤

抖音（个人号）：工作手机号注册 → 完善资料 → 养号3–5天（每天刷15–30分钟房产/家居/本地内容，点赞评论）→ 有经纪人证的可做个人职业认证（黄V），没有就直接发内容 → 从知识分享和实景实拍开始，不一上来发硬广。

小红书（个人号）：工作手机号注册 → 完善资料（昵称"靖西买房｜姓名"）→ 可选开通"个人专业号"（不是企业，不需营业执照，可解锁数据分析和置顶）→ 先刷3天本地房产笔记 → 图文笔记比视频更容易起步。

快手（个人号）：工作手机号注册 → 完善资料 → 先拍工作日常和看房vlog，快手用户偏好真实接地气的内容 → 有经纪人证可做个人职业认证。

视频号（个人号）：工作微信开通 → 完善资料 → 与微信打通，朋友圈好友直接可见 → 有经纪人证可做个人职业认证（一年仅2次机会，材料齐全再提交）→ 未认证时尽量不发"房源推荐"类视频，多发买房知识、配套、小区实景、工作日常。

个人账号避免违规的8条核心建议

① 定位为"买房顾问"，不是"售楼员"：内容以知识分享、实景展示、避坑指南为主，不要让账号看起来像纯广告号。

② 不在公域留任何联系方式：视频、简介、评论区、私信自动回复都不出现手机号/微信/二维码。客户问就回"私信我"，私信里再加微信。谐音（"薇""v""扣"）也不行。

③ 不公开报价、不喊优惠：不写具体价格、"特价""内部价""友情价"。统一说"具体价格以案场公示为准，私信了解"。

④ 主页亮身份，主动合规：简介写明真实姓名、所属机构，如"靖西买房顾问小李｜龙城·誉峰天境置业顾问｜所属XX房产经纪"。主动亮身份降低被误判为"黑中介"的风险。

⑤ 有证的尽量做个人职业认证：有经纪人资格证的，优先在抖音和视频号做黄V认证，权重更高、限流风险更低。没有证不要造假，普通个人号做知识分享完全可行。

⑥ 用"分享"语气，不用"销售"语气：✅"今天带大家看看这个现房小区的实景" ❌"最好的现房赶紧来找我买"。分享语气是"我告诉你一个信息"，销售语气是"你快来买"。

⑦ 转化走私信→微信→线下：结尾引导用"感兴趣的私信我""有问题评论区问我"，不说"加我微信""打电话"。所有交易动作（报价、收定金、签约）都在线下售楼部完成。

⑧ 用工作手机号，与生活号隔离：四个平台用同一个工作手机号注册，不用个人生活号。工作号被限流不影响个人生活，建议专门办一张工作手机卡。

03内容创作基础：拍视频、拍照片、配文

3.1 拍视频：手机就能拍的6种简单形式

① 一镜到底口播

手机架在面前，对着镜头讲一个知识点或卖点。最容易上手，最能建立人设。

时长30–60秒

要点开头3秒抛问题，中间讲1–2个点，结尾引导关注/私信

② 样板间走拍

手机举着边走边拍，从入户→客厅→阳台→卧室，边走边介绍。最直观展示产品。

时长60–90秒

要点横平竖直，走路稳，每个空间停2–3秒，重点讲窗外景观和采光

③ 配套实拍

实地拍学校、商场、菜市场、公园，证明"配套是真的"。信任感最强。

时长30–60秒

要点拍大门招牌+内部环境+步行到项目的路线，口播说明距离和时间

④ 对比类视频

期房vs现房、同价位不同项目、真假学区对比。容易出爆款。

时长45–75秒

要点只讲事实不踩竞品，用"我们项目的特点是…"代替"别人家不行"

⑤ 客户问答/答疑

把客户常问的问题一条条回答。精准获客，看的人都是潜在客户。

时长30–60秒

要点标题直接用问题，如"靖西买房能马上办证吗？"

⑥ 工程进度/小区日常

拍工地施工、园林养护、物业保洁、业主活动。体现靠谱和真实。

时长20–45秒

要点定期更新，让客户看到"每天都在变化"

手机拍摄5个基本功

  1. 擦镜头：拍之前用衣服擦一下手机镜头，模糊是最常见的低级错误。
  2. 横平竖直：打开手机相机的"网格线"，让墙面、地平线和网格线平行。
  3. 光线充足：尽量白天拍，室内开灯+拉开窗帘，不要逆光（人站在窗前脸会黑）。
  4. 稳定：双手持机或靠墙/靠桌子，有条件买一个几十元的手机三脚架+蓝牙遥控器。
  5. 收音清楚：口播时离手机1米以内，环境安静；风大时用手挡一下麦克风或买领夹麦（百元内）。

  • "马路对面就是菜市场，住进来才知道有多方便"

差标题（不要用）：

  • "好房推荐"（太泛，没人点）
  • "龙城誉峰天境欢迎您"（像广告，平台限流）
  • "震惊！靖西最好的房子"（夸张违规，平台打压）

正文结构（决定完读率和咨询率）

开头钩子（1–2句抓住注意力）
→ 中间卖点（2–3个，每个配具体事实/数字）
→ 结尾行动号召（引导私信/评论/到售楼部）

话题标签怎么加

  • 视频号：2–3个即可，视频号靠社交转发，标签作用相对小

04四平台差异化内容策略

四个平台的用户习惯和算法逻辑完全不同，不能一条视频发四个平台就完事。同一条素材要根据平台特点做改编。

4.1 抖音：短视频+直播，强转化

平台特点：算法推荐为主，流量大，用户习惯刷短视频，房产类内容竞争激烈但转化路径短（可直接挂组件/留资）。

内容方向：

  • 探盘视频：第一视角带看样板间，节奏快，3秒内出画面亮点
  • 干货口播：买房避坑、贷款知识、办证流程，建立专业形象
  • 剧情/反差："客户以为期房便宜，算完账发现现房更划算"这类小剧情
  • 直播：每周固定时间直播探盘/答疑，直播间挂小风车留资

爆款结构：开头冲突/疑问 → 快速展示3个卖点 → 价格/优惠信息 → 引导私信

4.2 小红书：图文种草，强搜索

平台特点：搜索属性强，用户会主动搜"靖西买房""靖西学区房"，内容生命周期长（一篇笔记半年后还能被搜到）。女性用户多，决策影响力大。

内容方向：

  • 图文笔记（主力）：6–9张图，封面要有大字标题，内页讲清楚配套、户型、价格
  • 买房攻略："靖西买房攻略｜5个必看小区""第一次买房怎么选楼层"
  • 生活方式："住在喀斯特山景房是什么体验""靖西周末遛娃地图"
  • 对比测评：同价位3个小区横向对比，客观列出优缺点

关键技巧：标题和正文里大量布局搜索关键词（靖西、现房、学区、办证、誉峰天境），让客户搜得到。封面用醒目的大字+实景图，不要用纯效果图。

4.3 快手：真实接地气，强信任

平台特点：下沉市场用户多，偏好真实、接地气、有人情味的内容。信任关系强，粉丝粘性高，"老铁经济"明显。

内容方向：

  • 真实日常：售楼部的一天、带客户看房全过程、工地实拍
  • 口语化讲解：不用专业术语，用大白话讲"这个房子好在哪"
  • 业主故事：采访已购房业主为什么选这里（需征得同意）
  • 直播带看：快手直播转化率高，固定时间直播，和粉丝像朋友一样聊天

关键技巧：人设要"实在"，不要端着。多和评论区互动，回复每一条评论。价格、优惠可以说得更直接，但不能虚假承诺。

4.4 视频号：私域裂变，强社交

平台特点：基于微信社交关系链，朋友点赞/转发会带来曝光。用户年龄偏大，购买力强，是老带新和圈层营销的最佳阵地。

内容方向：

  • 项目品质展示：园林、物业、工程细节，适合转发给亲友"你看这个盘不错"
  • 业主活动/社区文化：中秋活动、亲子活动、邻里节，体现社区氛围
  • 权威背书：政务中心就近办证、中医医院配套、学校实拍，增强可信度
  • 直播：视频号直播可直接转发到微信群和朋友圈，配合社群运营效果好

关键技巧：每条视频发完后自己先转发到朋友圈+业主群+客户群，请同事和老客户帮忙点赞转发。视频号的冷启动完全靠社交裂变。

4.5 一鱼多吃：一条素材怎么改编成四个平台

原始素材抖音小红书快手视频号
样板间走拍视频（90秒） 剪成30秒快节奏版，加字幕和BGM，开头直接出阳台山景 截图6–9张做图文笔记，标题"靖西山景现房实拍｜每个房间都有光" 发完整90秒版，口播更口语化，标题"老铁们看看这房子中不中" 剪成60秒温情版，配舒缓音乐，标题"在靖西，有这样一个家"
核心：抖音重节奏、小红书重图文搜索、快手重真实口语、视频号重品质和社交转发

5.1 用AI写文案和脚本

适用工具：豆包AI画图、Midjourney、即梦等。

常用场景：

  • 客厅/卧室效果图：当样板间还没开放或需要不同风格展示时，用AI生成室内效果图，窗外可指定广西喀斯特风光
  • 小红书封面图：生成带大字标题的封面，比纯文字更吸睛
  • 节日海报：中秋、国庆、元旦等节点快速生成节日祝福海报

提示词模板：室内效果图

横版[现代轻奢/新中式/奶油风]高层住宅客厅室内效果图，写实建筑摄影质感，广角视角。

5.3 用AI做视频

数字人口播：用HeyGen、硅基智能等工具，上传一段自己的视频，生成数字人，以后写好文案就能自动生成口播视频。适合批量产出干货内容。

智能剪辑：用剪映的"图文成片""智能字幕""一键成片"功能，输入文案自动匹配画面和字幕，5分钟出一条视频。

AI配音：剪映自带AI配音，选择自然的男声/女声，不用自己录音，适合不善出镜的同事。

5.4 AI使用红线（必须遵守）

🚫 AI不能做的事
  1. 不能编造事实：AI可能编造不存在的配套、价格、政策。所有涉及项目具体信息（价格、面积、学区、配套名称、办证时间）必须人工核实，以项目官方资料为准。
  2. 不能承诺疗效/升值/收益：AI容易写出"稳赚不赔""升值潜力大"等违规表述，发布前必须删掉。
  3. 不能用极限词：AI喜欢用"最好""顶级""第一""绝版"，发布前逐条检查替换。
  4. 不能泄露客户隐私：不要把客户姓名、电话、购房信息输入AI工具。
  5. AI生成内容必须人工审核：AI是助手不是审核员，每条内容发布前置业顾问自己必须通读一遍。

6.3 平台规则易错点

  • 抖音：视频里不要出现二维码、微信ID、手机号；直播不要说"加微信"，用"点击小风车""私信我"代替。
  • 小红书：不要在评论区留微信，不要用"薇""v"等谐音暗示联系方式；图片上不要压太多文字（影响推荐）。
  • 快手：不要频繁发完全相同的内容（被判搬运）；直播不要夸大优惠、不要虚假承诺。
  • 视频号：不要诱导分享（"不转不是靖西人"这类会被限流）；不要发未经证实的市场预测和政策解读。

6.4 客户隐私与个人信息

⚠️ 隐私保护
  • 拍视频/照片时，客户的脸、姓名、电话、购房信息必须打码或避开，除非客户书面同意出镜。
  • 不要在公开内容中透露具体成交价、客户职业、家庭情况等隐私。
  • 业主群聊天记录不要截图发公域平台。
  • AI工具不要输入客户个人信息。

6.5 常见限流/封号原因自查表

如果流量突然下降，按以下顺序自查：

  1. 最近是否发了含极限词/承诺升值的内容？→ 删除并修改
  2. 是否在视频/简介/评论区留了联系方式？→ 移除
  3. 是否被多人举报？→ 检查评论区是否有争议内容
  4. 是否断更超过2周？→ 恢复稳定更新
  5. 账号资质是否过期/未年审？→ 检查企业号认证状态
  6. 是否用了AI生成的虚假效果图未标注？→ 补充标注

周二–周四集中拍摄，一次拍够一周的素材（2–3小时集中拍，比每天拍效率高）
周五剪辑+配文，排好下周发布计划
周末直播1–2场（探盘/答疑），周末客户空闲时间多
周日晚复盘：本周哪条数据最好？为什么？下周优化方向

7.4 数据复盘看什么

  • 播放量/阅读量：低于账号平均值50%，说明封面/标题不行，下次优化
  • 完播率：视频低于30%，说明开头不吸引人或节奏太慢
  • 点赞/评论/收藏比：收藏高说明内容有价值（攻略类），评论高说明有争议或共鸣
  • 私信量：这是最核心的指标——有多少人主动咨询，直接关联到访和成交
  • 不要只看播放量：一条10万播放但0私信的视频，不如一条1000播放但5个私信的视频

08常见问题FAQ

Q1：我不会拍视频、不会剪辑，能做吗？

A：能。现在手机自带相机就能拍，剪映的"一键成片""图文成片"功能可以自动剪辑加字幕。先从最简单的口播开始，对着手机说话就行，不需要任何技术。真实感比精致更重要。

Q2：我没时间做，每天带客户都忙不过来？

A：线上推广就是带客户的另一种方式。建议每周集中2–3小时拍好一周素材，每天只花30分钟发布和互动。前期投入时间，后期客户主动找你，反而节省拓客时间。

Q3：发了几条没流量，还要坚持吗？

A：要。新账号前20条内容都是"测试期"，平台在判断你的账号标签。坚持发20条以上、持续1个月，流量才会稳定。中间不断优化标题和封面，不要发3条没效果就放弃。

Q4：四个平台都要做吗？能不能只做一个？

A：建议先主攻1个，再铺其他。新手可以先做抖音（流量最大）或视频号（最容易启动，靠朋友圈转发），做出感觉后再复制到其他平台。本手册的"一鱼多吃"方法就是让你用一套素材覆盖四个平台，不会增加太多工作量。

Q5：直播必须做吗？我不敢出镜？

A：直播不是必须，但做了效果更好。不敢出镜可以先做"语音直播"或"画面直播"（镜头对着样板间，人在画外讲解）。等熟悉了再出镜。直播是转化率最高的形式，建议每周至少1场。

Q6：AI写的文案能直接用吗？

A：不能直接用，必须人工审核修改。AI容易出现极限词、虚假承诺、编造信息。正确用法是：AI出初稿 → 你修改事实数据 → 删除违规表述 → 加上自己的口语化表达 → 发布。

Q7：客户在评论区问价格，怎么回答？

A：不要在评论区直接报具体价格（价格可能变动，且公开报价有合规风险）。统一回复："价格具体看楼层和户型，私信我发你详细价格表，也可以来售楼部实地了解。"引导到私信或案场。

Q8：同行/竞品在评论区恶意评论怎么办？

A：不要对骂，不要删除（删除可能引发更多）。礼貌回复事实即可，如"感谢关注，我们项目的具体情况可以来售楼部实地了解。"其他用户看到你的专业态度反而加分。严重恶意攻击可举报。

Q9：账号被限流了怎么办？

A：先按第6.5节自查表排查。删除违规内容，停更2–3天，恢复正常刷视频互动，然后重新发合规内容。如果是资质问题，尽快补齐企业认证和房产类目资质。

Q10：怎么衡量我做线上有没有效果？

A：看三个指标，按优先级排序：

  1. 私信咨询量：每周有多少人主动问房子（核心指标）
  2. 到访量：有多少客户说是看了你的视频来售楼部的
  3. 成交量：线上客户最终成交了几套

播放量只是过程指标，私信和到访才是结果指标。建议每个置业顾问建一个简单表格，记录每条内容带来的私信和到访。

✨ 最后一句话 线上推广没有秘诀，就是真实、持续、合规。把你每天在售楼部跟客户说的话，对着手机再说一遍，发到网上，就会有更多客户听到。开始做，比做得完美更重要。
